# Kite

A low-data messaging app that lets you message anyone by phone number.

**Features:**
- Phone number sign-up with OTP verification
- Chat by phone number
- Low-bandwidth design (text-only)
- Light/dark blue theme
- Data saver mode
- Feed for sharing updates

**Tech:**
- React 18 (UMD build via CDN)
- Client-side storage (localStorage fallback)
- Single-file deployment (133 lines)
